## Client notes

- **pycurl** — libcurl easy handle for sequential work; CurlMulti (no threads) for concurrency.
- **httpx2** — httpx2.Client; concurrency via threads sharing one client. HTTP/2 from many threads is intermittently unsafe: httpcore2 can emit stream IDs out of order and the server answers GOAWAY(PROTOCOL_ERROR) (seen in ~1 of 5 `concurrent_small` h2 runs).
- **httpx2-async** — httpx2.AsyncClient on asyncio.
- **httpcore2** — httpcore2.ConnectionPool directly (the transport underneath httpx2); same threaded-HTTP/2 stream-ordering race as httpx2.
- **httpcore2-async** — httpcore2.AsyncConnectionPool on asyncio.
- **urllib3** — PoolManager; h2 = experimental urllib3.http2.inject_into_urllib3() (TLS only, one request per connection at a time, no multiplexing, request bodies larger than the peer's flow-control window are rejected).
- **requests** — Session + HTTPAdapter. HTTP/1.1 only: requests has no HTTP/2 support, and urllib3's experimental h2 connection rejects the arguments requests passes.
- **aiohttp** — ClientSession; aiohttp has no HTTP/2 client support.
